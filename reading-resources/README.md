# Reading Resources
This file contains the links for papers, documentations and other stuff I had to read for this project. It will (hopefully) evolve over time. 


## xApps Basics

**Managing O-RAN Networks: xApp Development from Zero to Hero [link](https://arxiv.org/pdf/2407.09619)**: Introduction to architecture, basics, examples and the nesecary information to get a sense about xApps, their interface and how they can be developed and deployed

**Onboarding and Deployment of Hw-go xApp [link](https://docs.o-ran-sc.org/projects/o-ran-sc-ric-app-hw-go/en/latest/onboard-and-deploy.html)**

**xApp development framework by ORAN: [XAPP-FRAME](https://github.com/o-ran-sc/ric-plt-xapp-frame)**: Details various APIs, including metrics, RMR and 
SDL. Includes an example fully functional xApp written in Go. 

## Hands-on Tutorials

**O-RAN-SC Installation Guide [link](https://docs.o-ran-sc.org/projects/o-ran-sc-ric-plt-ric-dep/en/latest/installation-guides.html)**

**Building Your First O-RAN xApp: A Step-by-Step Tutorial [link](https://www.5g6gacademy.com/learn/oran-ric-xapp-development-tutorial)**: Step by step, for defining and building your first xApp, includes keywords you can search to get more content

**Configuration E2SIM [link](https://hackmd.io/@abdfikih/BJ-dnZIbA)**: Explains how to build and deploy the E2 simulator on your K8s cluster
